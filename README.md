# NLP with Deep Learning

A collection of hands-on implementations covering core NLP and generative AI topics, built while following the Optiwisdom NLP & LLM course.

---

## What's Inside

| Folder | Description |
|--------|-------------|
| `RNN` | Text generation and sequence modeling with Recurrent Neural Networks |
| `LSTM` | Long Short-Term Memory networks for NLP tasks |
| `GPT` | Working with OpenAI GPT API for text generation |
| `GPT VOICE` | Voice input + GPT integration |
| `GEMINI` | Experiments with Google Gemini API |
| `LLAMA` | Running and prompting LLaMA models locally via Ollama |
| `AI AGENT` | Building a simple AI agent with tool use |

## Tech Stack

`Python` `PyTorch` `Transformers` `OpenAI API` `Gemini API` `Ollama` `LLaMA`

## Purpose

These are personal practice notebooks and scripts — not a finished product. The goal was to build intuition for how different NLP architectures and LLM APIs work in practice.
